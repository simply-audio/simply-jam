# Musical guidance

How a set should feel and move, for an agent that plays the pictures and the room beside the music: when to build and when to leave space, what the drop is for, how the pictures follow the song's journey rather than every beat.

One file per idea. Agents read this folder before choosing a look.

---

Tussen keeps your vibes, routings, takes and shader library in `~/Music/simply.audio/tussen/` (the controller mappings, inputs and outputs stay in `~/.config/tussen/`); takes recorded by tussen 1.0 in `~/Music/tussen/takes/` are still listed.
